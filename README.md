# Rock, Paper, Scissors (Lizard, Spock)

Originally a Codedex project, I adjusted and expanded the base game to my liking. Instead of just building standard Rock, Paper, Scissors or forcing the Lizard, Spock variant, I engineered a choice system for the player. 

This was a fun project to build and a great way to practice Python logic and game loops!

## Features
* **Dual Game Modes:** Players can choose to play the classic game or the extended Lizard, Spock version.
* **Continuous Play:** Implemented a continuous game loop allowing the user to play multiple rounds or quit at their own pace.
* **Modular Code:** Separated the game logic and number checking into distinct files (`logic.py`, `check_number.py`) for cleaner architecture.

## Languages Used
* Python
